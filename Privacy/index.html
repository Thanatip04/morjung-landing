แอปพลิเคชัน Morjung

อัปเดตล่าสุด: 19 พฤษภาคม 2026

Morjung ให้ความสำคัญกับความเป็นส่วนตัวและความปลอดภัยของข้อมูลส่วนบุคคลของผู้ใช้งาน นโยบายฉบับนี้อธิบายถึงแนวทางในการเก็บรวบรวม ใช้งาน เปิดเผย และปกป้องข้อมูลส่วนบุคคลของคุณ เพื่อให้สอดคล้องกับพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA)

การเข้าใช้งานแอปพลิเคชัน Morjung ถือว่าคุณรับทราบและยอมรับแนวทางปฏิบัติตามนโยบายฉบับนี้

ข้อมูลส่วนบุคคลที่เราเก็บรวบรวม

เราเก็บรวบรวมข้อมูลส่วนบุคคลเท่าที่จำเป็นต่อการให้บริการ การพัฒนาแพลตฟอร์ม และการยกระดับประสบการณ์การใช้งานของผู้ใช้

1.1 ข้อมูลบัญชีผู้ใช้งาน

  • ชื่อผู้ใช้งาน (Username)
  • ที่อยู่อีเมล (Email Address)
  • รูปโปรไฟล์
  • ข้อมูลการเข้าสู่ระบบและการยืนยันตัวตน

1.2 ข้อมูลตำแหน่ง

Morjung เป็นแพลตฟอร์มที่ใช้ระบบการเช็กอินตามตำแหน่งจริงของผู้ใช้งาน

  • ข้อมูล GPS แบบ Real-time
  • ข้อมูลตำแหน่งโดยประมาณจาก IP Address หรือเครือข่าย
  • ประวัติการเช็กอิน
  • สถานที่ที่ผู้ใช้บันทึกหรือกดถูกใจ
  • ข้อมูลการใช้งานแผนที่ภายในแอปพลิเคชัน

1.3 เนื้อหาที่ผู้ใช้สร้างขึ้น

  • รูปภาพ
  • วิดีโอ
  • รีวิว
  • ความคิดเห็น
  • โพสต์หรือข้อมูลสถานที่

ผู้ใช้ยังคงเป็นเจ้าของลิขสิทธิ์ในเนื้อหาที่ตนอัปโหลด อย่างไรก็ตาม การเผยแพร่เนื้อหาผ่านแพลตฟอร์มถือว่าคุณอนุญาตให้ระบบสามารถแสดงผล จัดเก็บ และประมวลผลข้อมูลดังกล่าวเพื่อการให้บริการ
* Morjung ขอสงวนสิทธิ์ในการลบ ระงับ หรือจำกัดการเข้าถึงเนื้อหาที่ขัดต่อกฎหมาย นโยบายชุมชน หรือสร้างผลกระทบต่อผู้ใช้งานรายอื่น

1.4 ข้อมูลทางเทคนิคและการใช้งาน

  • IP Address / ประเภทอุปกรณ์และระบบปฏิบัติการ
  • ประเภทเบราว์เซอร์ / ภาษา / เวลาในการเข้าใช้งาน
  • พฤติกรรมการใช้งานภายในระบบ / Cookies และ Session Data
  • Log การใช้งานระบบและบันทึกเหตุการณ์ (Log Data)

ข้อมูลดังกล่าวช่วยให้เราสามารถวิเคราะห์ ปรับปรุง และรักษาความปลอดภัยของระบบได้ดียิ่งขึ้น

การเข้าถึงอุปกรณ์และสิทธิ์การอนุญาต

เพื่อให้แอปพลิเคชันสามารถทำงานได้อย่างสมบูรณ์ เราอาจร้องขอสิทธิ์ในการเข้าถึงฟังก์ชันบางส่วนของอุปกรณ์ของคุณ

2.1 การเข้าถึงตำแหน่ง

  • ตรวจสอบการเช็กอิน ณ สถานที่จริง
  • แสดงแผนที่และสถานที่ใกล้เคียง
  • ปรับปรุงคำแนะนำการใช้งาน

2.2 การเข้าถึงกล้อง

  • ถ่ายรูปหรือวิดีโอเพื่อสร้างโพสต์
  • อัปโหลดคอนเทนต์เข้าสู่แพลตฟอร์ม

2.3 การเข้าถึงรูปภาพและไฟล์

  • เลือกรูปภาพหรือวิดีโอจากอุปกรณ์
  • บันทึกหรือจัดเก็บสื่อที่เกี่ยวข้องกับการใช้งาน

ผู้ใช้สามารถจัดการหรือเพิกถอนสิทธิ์เหล่านี้ได้ผ่านการตั้งค่าของอุปกรณ์ตลอดเวลา

วัตถุประสงค์ในการใช้ข้อมูล

  • เพื่อสร้างและจัดการบัญชีผู้ใช้งาน และยืนยันตัวตนการเข้าสู่ระบบ
  • เพื่อให้บริการฟังก์ชันเช็กอิน แผนที่ แสดงผลโพสต์และคอนเทนต์
  • เพื่อวิเคราะห์ ปรับปรุงระบบ และป้องกันการทุจริตหรือการใช้งานผิดปกติ
  • เพื่อส่งข้อมูล ข่าวสาร หรือการแจ้งเตือนจากระบบ และปฏิบัติตามกฎหมาย

ฐานทางกฎหมายในการประมวลผลข้อมูล

เราประมวลผลข้อมูลส่วนบุคคลภายใต้ฐานทางกฎหมายที่เหมาะสมตาม PDPA เช่น

  • ความยินยอมของผู้ใช้งาน (Consent) / การปฏิบัติตามสัญญา (Contract)
  • ประโยชน์โดยชอบด้วยกฎหมาย (Legitimate Interest) / การปฏิบัติตามกฎหมาย (Legal Obligation)

Cookies และเทคโนโลยีติดตามข้อมูล

  • จดจำสถานะการเข้าสู่ระบบและบันทึกการตั้งค่าผู้ใช้งาน
  • วิเคราะห์ประสิทธิภาพของระบบและปรับปรุงประสบการณ์การใช้งาน

ผู้ใช้สามารถปฏิเสธหรือลบ Cookies ได้ผ่านการตั้งค่าเบราว์เซอร์ของตนเอง อย่างไรก็ตาม การปิดใช้งาน Cookies บางประเภทอาจส่งผลให้บางฟังก์ชันของเว็บไซต์ทำงานได้ไม่สมบูรณ์

การเปิดเผยข้อมูลแก่บุคคลที่สาม

เรามีนโยบายไม่ขาย ให้เช่า หรือเปิดเผยข้อมูลส่วนบุคคลของคุณแก่บุคคลภายนอกเพื่อวัตถุประสงค์ทางการตลาด อย่างไรก็ตาม เราอาจเปิดเผยข้อมูลในกรณีดังต่อไปนี้

  • ผู้ให้บริการ Cloud Infrastructure และบริการวิเคราะห์ข้อมูล
  • ผู้ให้บริการแผนที่และระบบ Location / หน่วยงานรัฐตามที่กฎหมายกำหนด

ผู้ให้บริการภายนอกที่เราใช้งาน

  • Firebase
  • Google Analytics
  • Google Maps API
  • Cloudinary

การโอนข้อมูลไปต่างประเทศ

ข้อมูลบางส่วนอาจถูกจัดเก็บหรือประมวลผลบนเซิร์ฟเวอร์ของผู้ให้บริการภายนอกในต่างประเทศ เช่น Google Firebase หรือ Cloudinary ซึ่งมีมาตรการคุ้มครองข้อมูลตามมาตรฐานสากล

มาตรการรักษาความปลอดภัยของข้อมูล

  • การเข้ารหัสข้อมูล (Encryption) และการควบคุมสิทธิ์การเข้าถึง
  • Secure Authentication และการตรวจสอบความปลอดภัยของระบบ

ระยะเวลาในการจัดเก็บข้อมูล

  • ข้อมูลบัญชีจะถูกเก็บตราบเท่าที่บัญชียังใช้งานอยู่
  • ข้อมูล Cookies / Log ข้อมูลสำรองจะถูกเก็บตามรอบและระยะเวลาของระบบ

หากผู้ใช้งานร้องขอลบบัญชี ข้อมูลส่วนบุคคลจะถูกลบหรือทำให้ไม่สามารถระบุตัวตนได้ภายในระยะเวลาที่เหมาะสม เว้นแต่มีเหตุจำเป็นเพื่อปฏิบัติตามกฎหมาย หรือเพื่อความปลอดภัยของระบบ

สิทธิ์ของเจ้าของข้อมูลส่วนบุคคล

  • สิทธิ์ในการเข้าถึงและขอรับสำเนาข้อมูล
  • สิทธิ์ในการแก้ไขข้อมูลให้ถูกต้อง
  • สิทธิ์ในการคัดค้านการประมวลผล
  • สิทธิ์ในการถอนความยินยอม
  • สิทธิ์ในการขอให้ลบหรือทำลายข้อมูล
  • สิทธิ์ในการระงับการใช้ข้อมูล

ผู้ใช้งานสามารถยื่นคำร้องเพื่อใช้สิทธิ์เกี่ยวกับข้อมูลส่วนบุคคลได้ผ่านอีเมล support@morjung.com โดยเราจะดำเนินการภายในระยะเวลาที่กฎหมายกำหนด

ความเป็นส่วนตัวของผู้เยาว์

Morjung ไม่ได้มีวัตถุประสงค์ในการเก็บข้อมูลจากเด็กอายุต่ำกว่า 13 ปีโดยไม่มีความยินยอมจากผู้ปกครองอย่างถูกต้องตามแนวทางปฏิบัติ หากเราพบว่ามีการเก็บข้อมูลของผู้เยาว์โดยไม่เหมาะสม เราจะดำเนินการลบข้อมูลดังกล่าวโดยเร็วที่สุด
